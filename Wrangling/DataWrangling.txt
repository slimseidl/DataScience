Data Wrangling Summary 

    -  a set of processes for turning raw and messy data into a clean format to answer interesting questions from the data
    -  three phases to data wrangling:
        - gather 
        - assess
        - cleaning 
    - often done by analysts and can be used in conjunction with Extract, Transform, and Load
    - Environment needed for this course 

        - Jupyter
        - Notepad
        - Excel 
    - More Magic Keywords 
        - Terminal Commands in jupyter 
            - !mkdir 
            - %ls 
                - show file in active directory
            - %timeit 
    -Convert notebooks 
        - jupyter nbconvert --to FORMAT mynotebook.ipynb 
        - Formats:
            - HTML
            - Latex
            - PDF
            - Markdown
            - slideshow
            - ascii
            - notebooks
            - executable script
        - pip install nbconvert 

    - Real World Wrangling 

        - Define a questions
        - Gather the data 
            - variable sources
        - Assess Data 
            - missing data
            - outliers
            - innaccurate values 
        - Clean the Data 
            - clean up issues from previous step 
        - Answer the questions 
            - Draw conclusions
